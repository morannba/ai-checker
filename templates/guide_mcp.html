לחבר את Claude לגוגל אדס, Search Console ו-GA4

במקום לקפוץ בין שלוש מערכות ולייצא דוחות לאקסל, שואלים את Claude בשפה רגילה: „אילו קמפיינים הוציאו כסף בלי המרות החודש?”, „אילו עמודים מקבלים חשיפות בגוגל אבל כמעט לא קליקים?”. Claude שולף את הנתונים בעצמו, מהחשבונות שלכם.

למי זה מתאים

למי שמנהל פרסום בעצמו (או מנהל שיווק בחברה) ומשתמש כבר ב-Claude. לא צריך לדעת לתכנת, אבל צריך להיות בנוח עם הדבקת כמה פקודות בטרמינל ועריכה של קובץ הגדרות אחד.

מה צריך מראש:

  • Claude Desktop (Mac או Windows) או Claude Code.
  • גישה לחשבון Google Ads, לנכס GA4 ולנכס ב-Search Console, עם אותו חשבון גוגל.
  • חשבון Google Cloud (חינמי, לא צריך להפעיל חיוב בשביל המדריך הזה).

1הכנה: פרויקט ב-Google Cloud והכלים במחשב

א. פרויקט והפעלת ה-APIs

  1. נכנסים ל-Google Cloud Console ויוצרים פרויקט חדש (למשל claude-marketing). רושמים בצד את ה-Project ID.
  2. ב-APIs & Services → Library מפעילים (Enable) ארבעה APIs:
    • Google Analytics Admin API
    • Google Analytics Data API
    • Google Ads API
    • Google Search Console API

ב. מסך הסכמה ו-OAuth Client

  1. ב-Google Auth Platform (לשעבר OAuth consent screen) מגדירים אפליקציה. סוג משתמשים: External (או Internal אם יש לכם Google Workspace).
  2. ב-Audience מוסיפים את המייל שלכם תחת Test users.
  3. ב-Clients → Create client בוחרים Desktop app, ומורידים את קובץ ה-JSON. שומרים אותו במקום קבוע, למשל ~/claude-mcp/client_secret.json. אותו קובץ ישמש את כל שלושת החיבורים.
שימו לב: התחברות שפגה אחרי שבועכל עוד האפליקציה במצב Testing, גוגל מבטלת את ההתחברות אחרי 7 ימים, ו-Claude פתאום „מאבד” את הנתונים. לשימוש אישי אפשר ללחוץ Publish app ב-Audience. גוגל תציג אזהרה שהאפליקציה לא מאומתת, וזה בסדר כשאתם המשתמשים היחידים.

ג. כלים במחשב

  • Google Cloud CLI (הפקודה gcloud).
  • pipx, שמריץ את השרתים הרשמיים של גוגל ל-GA4 ול-Ads.
  • uv (הפקודה uvx), שמריץ את השרת של Search Console.

אחרי ההתקנה מוצאים את הנתיב המלא של כל כלי, כי Claude Desktop לא תמיד מכיר את ה-PATH של הטרמינל:

# Mac
which pipx uvx

# Windows (PowerShell)
Get-Command pipx, uvx | Select-Object -ExpandProperty Source

המדריך פתוח 👇

ממשיכים לשלב 2.

2התחברות אחת לכל השירותים

השרתים של GA4 ושל Google Ads קוראים את אותו קובץ התחברות של gcloud. אם מתחברים פעמיים, כל פעם עם הרשאה אחרת, ההתחברות השנייה דורסת את הראשונה ואחד החיבורים מפסיק לעבוד. לכן מתחברים פעם אחת, עם כל ההרשאות יחד:

gcloud auth application-default login \
  --client-id-file=$HOME/claude-mcp/client_secret.json \
  --scopes=https://www.googleapis.com/auth/analytics.readonly,https://www.googleapis.com/auth/adwords,https://www.googleapis.com/auth/cloud-platform

ב-Windows כותבים הכול בשורה אחת, בלי ה-\, ועם הנתיב המלא לקובץ.

נפתח דפדפן, מתחברים עם חשבון הגוגל שיש לו גישה לנכסים ומאשרים. בסוף מופיעה שורה כזו, ואת הנתיב שבה מעתיקים:

Credentials saved to file: [/Users/you/.config/gcloud/application_default_credentials.json]
למה בלי הרשאת Search Console כאן?השרת של Search Console לא משתמש ב-gcloud. הוא פותח חלון התחברות משלו בפעם הראשונה שמשתמשים בו (שלב 5).

3Google Analytics 4

משתמשים בשרת ה-MCP הרשמי של גוגל, google-analytics-mcp. הוא מריץ דוחות GA4 (כולל משפכים, המרות ונתוני זמן אמת), מציג את הנכסים ואת הקישורים ל-Google Ads, וכברירת מחדל רק קורא.

ההגדרה שלו בקובץ של Claude (את הקובץ המלא בונים בשלב 6):

"analytics-mcp": {
  "command": "/FULL/PATH/TO/pipx",
  "args": ["run", "analytics-mcp"],
  "env": {
    "GOOGLE_APPLICATION_CREDENTIALS": "/FULL/PATH/TO/application_default_credentials.json",
    "GOOGLE_CLOUD_PROJECT": "YOUR_PROJECT_ID"
  }
}

אין צורך במזהה נכס בהגדרות. Claude מוצא לבד את הנכסים שיש לכם גישה אליהם, ואפשר לומר לו באיזה נכס לעבוד.

4Google Ads

גם כאן יש שרת רשמי של גוגל, google-ads-mcp. הוא שולף כל נתון מהחשבון בשאילתות GAQL, ש-Claude כותב בעצמו.

א. Developer Token, החלק שהכי הרבה אנשים נתקעים בו

  1. הטוקן מונפק רק מחשבון מנהל (MCC). אם אין לכם, פותחים חשבון מנהל בחינם ומקשרים אליו את חשבון המודעות.
  2. בחשבון המנהל: Admin → API Center, ממלאים את הטופס ומקבלים טוקן.
  3. טוקן חדש מתחיל ברמת גישה מוגבלת. אם הוא ברמת Test, הוא עובד רק על חשבונות בדיקה, וצריך לבקש באותו מסך רמת גישה גבוהה יותר. גוגל בודקת את הבקשה, וזה יכול לקחת כמה ימים.

ב. ההגדרה

"google-ads-mcp": {
  "command": "/FULL/PATH/TO/pipx",
  "args": ["run", "--spec", "git+https://github.com/googleads/google-ads-mcp.git", "google-ads-mcp"],
  "env": {
    "GOOGLE_APPLICATION_CREDENTIALS": "/FULL/PATH/TO/application_default_credentials.json",
    "GOOGLE_PROJECT_ID": "YOUR_PROJECT_ID",
    "GOOGLE_ADS_DEVELOPER_TOKEN": "YOUR_DEVELOPER_TOKEN",
    "GOOGLE_ADS_LOGIN_CUSTOMER_ID": "1234567890"
  }
}
  • GOOGLE_ADS_LOGIN_CUSTOMER_ID הוא מספר חשבון המנהל, בלי מקפים. צריך אותו כשהגישה לחשבון המודעות עוברת דרך חשבון מנהל.
  • הטוקן הוא סוד. לא שולחים אותו בצ'אט, לא שומרים אותו בגיט ולא מצלמים מסך שהוא מופיע בו.
האם Claude יכול לשנות משהו בחשבון?השרת כולל גם כמה פעולות כתיבה (נכסים ותוויות), אבל כל שינוי עובר קודם „הצעה” ורק אחרי אישור מפורש מתבצע. מי שרוצה קריאה בלבד יכול לכבות אותן בקובץ tools_config.yaml של השרת (assets: false, labels: false).

5Google Search Console

לגוגל אין (נכון לנובמבר 2026) שרת MCP רשמי ל-Search Console, ולכן משתמשים בשרת קוד פתוח מוכר, mcp-gsc. הוא שולף שאילתות, עמודים, CTR ומיקומים, משווה בין תקופות ובודק אינדוקס של כתובות.

"gsc": {
  "command": "/FULL/PATH/TO/uvx",
  "args": ["mcp-search-console"],
  "env": {
    "GSC_OAUTH_CLIENT_SECRETS_FILE": "/FULL/PATH/TO/client_secret.json"
  }
}

זה אותו קובץ client_secret.json משלב 1. בפעם הראשונה ש-Claude משתמש בו ייפתח דפדפן להתחברות, ומשם הוא זוכר.

נכס מסוג Domainאם הנכס ב-Search Console הוא מסוג Domain, הכתובת שלו היא sc-domain:example.co.il ולא https://example.co.il/. כש-Claude לא „מוצא” את האתר, זו כמעט תמיד הסיבה.

6קובץ ההגדרות המלא

Claude Desktop: Settings → Developer → Edit Config. זה פותח את הקובץ:

  • Mac: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

מדביקים את זה, ומחליפים כל ערך באותיות גדולות בערכים שלכם:

{
  "mcpServers": {
    "analytics-mcp": {
      "command": "/FULL/PATH/TO/pipx",
      "args": ["run", "analytics-mcp"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/FULL/PATH/TO/application_default_credentials.json",
        "GOOGLE_CLOUD_PROJECT": "YOUR_PROJECT_ID"
      }
    },
    "google-ads-mcp": {
      "command": "/FULL/PATH/TO/pipx",
      "args": ["run", "--spec", "git+https://github.com/googleads/google-ads-mcp.git", "google-ads-mcp"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/FULL/PATH/TO/application_default_credentials.json",
        "GOOGLE_PROJECT_ID": "YOUR_PROJECT_ID",
        "GOOGLE_ADS_DEVELOPER_TOKEN": "YOUR_DEVELOPER_TOKEN",
        "GOOGLE_ADS_LOGIN_CUSTOMER_ID": "YOUR_MANAGER_ID_NO_DASHES"
      }
    },
    "gsc": {
      "command": "/FULL/PATH/TO/uvx",
      "args": ["mcp-search-console"],
      "env": {
        "GSC_OAUTH_CLIENT_SECRETS_FILE": "/FULL/PATH/TO/client_secret.json"
      }
    }
  }
}
  • ב-Windows כותבים נתיבים עם לוכסן כפול: C:\\Users\\you\\claude-mcp\\client_secret.json.
  • אם כבר יש בקובץ mcpServers, מוסיפים את שלושת הבלוקים לתוכו ולא יוצרים עוד אחד.
  • שומרים, סוגרים את Claude לגמרי (Cmd+Q ב-Mac, או מה-tray ב-Windows) ופותחים מחדש. בתפריט הכלים בצ'אט אמורים להופיע שלושת החיבורים.

Claude Code: אותם שלושה בלוקים נכנסים תחת mcpServers בקובץ .mcp.json בתיקיית הפרויקט, או מוסיפים כל אחד בפקודה claude mcp add. בודקים עם /mcp.

7שאלות ראשונות ששווה לשאול

מתחילים בבדיקה שהכול מחובר:

איזה נכסי GA4, חשבונות Google Ads ואתרים ב-Search Console יש לי גישה אליהם?

ואז לשאלות שבאמת חוסכות זמן:

  • „אילו קמפיינים בגוגל אדס הוציאו יותר מ-500 ₪ ב-30 הימים האחרונים בלי אף המרה?”
  • „אילו מונחי חיפוש הביאו קליקים בתשלום, ואני כבר מדורג עליהם אורגנית בעמוד הראשון?”
  • „אילו עמודים מקבלים הרבה חשיפות ב-Search Console אבל CTR מתחת ל-1%? תציע כותרות חדשות.”
  • „תשווה בין ההמרות שגוגל אדס מדווח לבין מה ש-GA4 רואה מתנועה ממומנת, לפי קמפיין. איפה הפער הכי גדול?”
  • „מה דף הנחיתה עם שיעור ההמרה הכי נמוך מתנועה ממומנת, ומה היה שונה בו בחודש שעבר?”
הטריק שעושה את ההבדלClaude לא יודע מה נחשב אצלכם „ליד טוב”, איך נקראים הקמפיינים ומה כל המרה מייצגת. כמה שורות הסבר בתחילת השיחה (או ב-Project עם הוראות קבועות) משפרות את התשובות יותר מכל דבר אחר.

8שגיאות נפוצות ואיך לפתור אותן

מה רואיםמה לעשות
spawn pipx ENOENT או spawn uvx ENOENT, או שהחיבור לא מופיעClaude Desktop לא מוצא את הכלי. שמים ב-command את הנתיב המלא משלב 1ג.
Access blocked או „האפליקציה לא אומתה” בהתחברותמוסיפים את המייל שלכם ל-Test users (שלב 1ב), או ממשיכים דרך Advanced כשמדובר באפליקציה שלכם.
insufficient authentication scopes / ACCESS_TOKEN_SCOPE_INSUFFICIENTההתחברות נעשתה בלי אחת ההרשאות. מריצים שוב את הפקודה משלב 2, עם כל ההרשאות יחד.
DEVELOPER_TOKEN_NOT_APPROVEDהטוקן ברמת Test. מבקשים רמת גישה גבוהה יותר ב-API Center.
USER_PERMISSION_DENIED בגוגל אדסחסר או שגוי GOOGLE_ADS_LOGIN_CUSTOMER_ID: מספר חשבון המנהל, בלי מקפים.
SERVICE_DISABLED / „API has not been used in project”אחד מארבעת ה-APIs לא הופעל בפרויקט (שלב 1א), או שה-Project ID בקובץ שגוי.
אחרי שבוע הכול מפסיק לעבוד עם invalid_grantהאפליקציה במצב Testing. מפרסמים אותה (Publish app) ומתחברים שוב.
GA4 מחזיר רשימה ריקההתחברתם עם חשבון גוגל אחר מזה שיש לו גישה לנכס. מתחברים שוב עם החשבון הנכון.

אם יש שגיאה בקובץ ההגדרות עצמו (פסיק חסר, מירכאות), Claude Desktop מציג הודעה כשהוא עולה. אפשר להדביק את הקובץ ב-jsonlint.com בלי הסודות כדי למצוא את השגיאה.
