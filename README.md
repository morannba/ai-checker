# בודק נראות ב-AI

הכלי שואל את ChatGPT (ואופציונלית גם את Gemini ו-Claude) את השאלות שלקוח היה שואל בתחום של העסק, עם חיפוש ברשת.
הוא מראה אם העסק הופיע, מי הופיע במקומו, ועל אילו אתרים ה-AI נשען. בנוסף הוא בודק:
- אם הבוטים של AI חסומים ב-robots.txt או בחומת האש
- אם התוכן נקרא בלי JavaScript, כמו שבוטים קוראים אותו
- אילו כלי מדידה ופרסום מותקנים באתר

אין ציון. כל ממצא מסומן כ"נבדק בפועל", "הערכה" או "לא נבדק".

## הפעלה על המחשב (Windows)

1. מתקינים Python 3.12 מ-python.org, ומסמנים בהתקנה Add Python to PATH.
2. פותחים טרמינל בתיקייה הזו (או פותחים אותה ב-Claude Code ומבקשים ממנו להריץ את השלבים):
   ```
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   playwright install chromium
   ```
3. מעתיקים את `.env.example` לקובץ חדש בשם `.env`, ומדביקים בו את מפתחות ה-API (בפנקס רשימות).
4. מפעילים:
   ```
   py app.py
   ```
   ופותחים בדפדפן http://127.0.0.1:5000

## בדיקה מלאה מהטרמינל (כל המנועים, לשיחות עם לקוחות)

```
py run_check.py www.example.co.il "שם העסק" "רואה חשבון" "חיפה"
py run_check.py www.example.co.il "שם העסק" "רואה חשבון" "חיפה" --runs 3
```
הדוח נשמר ב-`data\reports`, ואפשר לראות אותו בדפדפן בכתובת שמודפסת בסוף (כשהאפליקציה רצה).

## לידים

כל בדיקה מהאתר נשמרת ב-`data\leads.csv` (נפתח באקסל), יחד עם סיכום הממצאים ופרמטרי ה-UTM של המודעה.
אם מגדירים `LEAD_WEBHOOK_URL` (למשל Webhook של Make), כל ליד נשלח גם לשם, ומשם אפשר להעביר למייל, לגיליון או ל-CRM.

## העלאה לאינטרנט (לקמפיין)

ב-Render.com (או Railway): Web Service חדש מתוך ריפו ב-GitHub.
- Build command: `pip install -r requirements.txt && playwright install --with-deps chromium`
- Start command: `gunicorn app:app --workers 1 --threads 8 --timeout 240 --bind 0.0.0.0:$PORT`
- את המפתחות מכניסים ב-Environment, לא בקוד.
- בשרת חינמי הקבצים נמחקים באתחול, ולכן שם חשוב להגדיר `LEAD_WEBHOOK_URL` כדי לא לאבד לידים.

## בדיקה בלי אינטרנט

`py tests\e2e_mock.py` מריץ את כל הזרימה מול אתרים ומנועי AI מדומים.

## עלויות

כל בדיקה ציבורית = 3 שאלות × 2 הרצות + שאלת "מה אתה יודע על העסק", כולן עם חיפוש ברשת, ועוד קריאות קצרות לניתוח התשובות.
את העלות לבדיקה כדאי למדוד בלוח הבקרה של OpenAI אחרי 5–10 בדיקות, ולהגדיר שם תקרת הוצאה חודשית.
